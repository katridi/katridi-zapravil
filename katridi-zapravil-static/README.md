# Катриди заправил

Минимальная статичная страница подкаста.

## Локальный просмотр

Можно просто открыть `index.html` в браузере.

## GitHub Pages

После загрузки файлов в репозиторий:

1. Открыть **Settings → Pages**.
2. В разделе **Build and deployment** выбрать **Deploy from a branch**.
3. Branch: `main`.
4. Folder: `/ (root)`.
5. Нажать **Save**.

После этого GitHub опубликует страницу на адресе вида:

`https://katridi.github.io/katridi-zapravil/`

## Перед публичным запуском

- заменить `assets/cover-placeholder.svg` на настоящую обложку;
- заменить `#` в кнопках на ссылки Яндекс Музыки, Spotify, Apple Podcasts и YouTube;
- обновить описание первого выпуска;
- позже добавить RSS и страницы выпусков.
